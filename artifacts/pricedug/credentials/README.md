# Android Release Signing

Release keystore for the PricedUG Android app. Used to sign release builds
(`./gradlew bundleRelease` / `assembleRelease`).

> ⚠️ **Security:** this keystore is your app's permanent signing identity. If this
> repo is ever public, treat the key as compromised — regenerate before shipping.

## How it's wired

`android/app/build.gradle` defines `signingConfigs.release` pointing at
`../../credentials/release.keystore`, and the `release` buildType uses it.

> **Note:** the `android/` folder is generated by `expo prebuild` and is
> gitignored. If it is regenerated, re-apply the `signingConfigs.release` block
> in `android/app/build.gradle` (the keystore file here is preserved).

## Rebuild the AAB

```bash
cd android && ./gradlew bundleRelease
# output: android/app/build/outputs/bundle/release/app-release.aab
```
